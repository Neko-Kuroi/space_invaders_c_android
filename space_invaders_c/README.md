# Space Invaders C 版

Neko-Kuroi の space_invaders のうち、原典 `spaceinvaders.py`（pygame 版、修正済み）を仕様の正本として C 言語（SDL2）へ移植したものです。計画は [PLAN.md](PLAN.md)、実装の記録は報告書にあります。

## 必要なもの

- Linux、gcc、make、pkg-config
- SDL2 の開発パッケージ: `libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev`

```
sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev
```

## ビルドと起動

```
make            # 実行ファイル space_invaders_c ができる
./space_invaders_c
make test       # 画面に依存しないロジックの単体テスト
```

素材（images/ sounds/ fonts/）は実行ファイルと同じ場所から読みます。フォルダごと移動しても、そのまま動きます。

## 操作

- タイトル画面: 何かキーを押して離すと開始
- A / D: 移動（押している間、原典と同じ式で加速します）
- S: 発射
- ESC（キーを離したとき）またはウィンドウを閉じる: 終了

## 構成

- `src/main.c` — SDL の初期化とイベントの読み取り。入力を Input 構造体に変えるだけ
- `src/game.c` / `game.h` — ゲームの進行と描画。原典の各メソッドと対応
- `src/logic.c` / `logic.h` — 敵の台帳、速度表、得点表、発射の規則、トーチカの設計表。SDL に触れないので単体テストができる
- `src/assets.c` / `assets.h` — 画像・音・フォントの読み込みと解放
- `tests/test_logic.c` — logic の単体テスト（67項目）

## 原典との関係で知っておくこと

- 原典の癖は再現してあります: 自機の加速式、敵集団が1行ずつ波のように動く動き、移動回数の初期値15、ラウンド2以降に開始直後の移動タイマーが「追いつきの速進」になること、敵の出現がずれる描画タイミング、ラウンド6以上で弾が残っていても3発追加されること、など
- 全域の `game` オブジェクト経由の相互参照は、Game 構造体にまとめてポインタで渡す形に置き換えました
- トーチカの地面は、原典では4基分が同じ位置に重なって生成されますが、同一位置なので1本にまとめてあります（見た目と当たり判定は等価です）
- 発射音は、原典では条件によって2つの音が重なる場合がありますが、C版では最後の音だけを鳴らします（聞き分けできない差として割り切りました）

## 外部レビューを受けて直したところ（2026-11-15）

- **敵集団が止まる不具合**: 原典にもともとあったバグです。波状移動のカウンタ（row_counter）の包み直しが「min_row−1 と一致したとき」だけだったため、上の行が全滅して min_row が上がると、カウンタが条件を飛び越えて敵が横にも下にも動かなくなることがありました。原典側を先に直し（条件を「以下」に変更し、reset でカウンタを初期値に戻す。回帰テスト付き）、C版にも同じ規則を `logic.c` の `fleet_counter_advance` として反映しました。**この点だけ、原典の元の挙動とは意図的に違います**（原典側も直してあるので、両版の現在の挙動は一致します）
- **爆発の消滅判定を描画から更新へ**: 以前は描画関数の中で爆発を消していたため、進行が描画に結び付いていました。消滅判定は更新側（`explosions_update`）に移し、描画は読むだけにしました
- **ミステリーシップ音の専用チャンネル**: 出現音は予約した専用チャンネル（0番）で鳴らします。以前は再生時のチャンネル番号を使い回していたため、音が終わったあとに別の効果音が同じ番号を使うと、その音をフェードアウトや停止で切ってしまう可能性がありました
- **自機弾とトーチカの当たり**: 原典は重なったセルを全部消しますが、C版は最初に当たった1セルだけを消していました。原典どおり全セルを消すようにし、敵弾側と処理を共通化しました

## 2回目のレビューを受けて直したところ

- **音声デバイスがなくても起動します**: 音声の初期化に失敗したときは、警告を出して音なしで続行します（WSL、CI、音声デバイスのない環境など）。このとき音の読み込みも行いません
- **更新と描画で同じ時刻を使います**: `game_render` は `now` を引数に取り、`game_update` と同じ時刻で爆発などを描きます
- **フレーム間隔を 60fps に合わせました**: 以前は 16ms 待つ方式で約 62.5fps になり、フレーム単位で動く量（弾の速さなど）がわずかに速くなっていました。高精度タイマーで次のフレームの開始時刻を積み上げて待ちます
- **ゲームオーバー中も爆発の寿命を進めます**（`explosions_update`）
- **起動の後始末**: 途中の初期化や素材の読み込みに失敗しても、それまでに確保したものを解放して終了します
- **`check_collisions` を分割**（(a)〜(h) をそれぞれ関数に。処理の順番は原典どおり）し、トーチカ・地面・自機・時間の数値に名前を付けました（`game.h`）。トーチカの判定は、基ごとの囲み矩形に触れたときだけセルを調べます

## このフォルダにある検証用のもの

- `.sdl/` と実行ファイル `space_invaders_c` は、作成した環境（Muse の VM）での検証用です。この VM では apt の依存関係の都合で SDL2 開発パッケージを通常インストールできなかったため、deb パッケージを展開したものを `.sdl/` に置いてビルドしました。通常の環境では上の手順どおり `make` だけでビルドできます
- スモークテスト: `SI_SMOKE_FRAMES=600 ./space_invaders_c` のように環境変数を付けると、入力を合成して指定フレームだけ回し、状態を表示して終了します
